Ánh xạ từ Tuyến Tính sang Xác Suất

Khi bắt đầu học AI, toán học thường là rào cản. Ở đây chúng ta học Hàm Sigmoid để giải quyết bài toán Phân Loại nhị phân. Công thức sigmoid biến đổi mọi giá trị tuyến tính $z = Wx + b$ thành một xác suất chính xác từ 0 đến 1.

Bản chất toán học

Hàm kích hoạt Sigmoid giúp thu hẹp vô hạn về khoảng 0 và 1:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Lập trình Python

Triển khai cực gọn bằng thư viện Numpy:

import numpy as np
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

Tối Ưu Hóa Chia Nhánh & Gradient Boosting

Từ cây quyết định đơn lẻ (Decision Tree), ta liên kết với toán thống kê để hiểu chỉ số Entropy và độ tinh khiết Gini. Sau đó phát triển lên thuật toán mạnh mẽ XGBoost và LightGBM thống trị dữ liệu bảng của doanh nghiệp.

Bản chất toán học

Tính độ hỗn loạn Entropy của dữ liệu để tìm điểm chia nhánh tốt nhất:

$$H(X) = -\sum P(x_i) \log_2 P(x_i)$$

Lập trình Python

Sử dụng thư viện scikit-learn và LightGBM thực chiến:

from lightgbm import LGBMClassifier

model.fit(X_train, y_train)

Nền Móng Deep Learning
Phần 1.3

Thuật Toán Lan Truyền Ngược (Backpropagation)

Mở rộng từ mô hình tuyến tính, ta liên kết nhiều neuron lại với nhau tạo thành mạng neural đa tầng. Cách mạng học dựa vào phép tính Đạo hàm chuỗi (Chain Rule) để tối ưu trọng số.

Bản chất toán học

Tính đạo hàm Chain Rule lan truyền lỗi ngược về các lớp trước:

$$\frac{\partial Loss}{\partial w} = \frac{\partial Loss}{\partial y\_pred} \times \frac{\partial y\_pred}{\partial z} \times \frac{\partial z}{\partial w}$$

Lập trình Python

Xây dựng Backprop thủ công bằng Numpy:

# Gradient step
d_weights = np.dot(X.T, (y_pred - y))
weights -= learning_rate * d_weights

Mạng Tích Chập CNN & Phép Nhân Ma Trận 2D

Từ mảng toán học ma trận, ta liên kết trực tiếp tới việc xử lý điểm ảnh 2D của máy tính. Sử dụng phép toán Tích chập (Convolution) để phát hiện cạnh, góc, và đối tượng trong ảnh.

Bản chất toán học

Phép toán tích chập nhân quét ma trận bộ lọc (Kernel) với ma trận ảnh đầu vào:

$$(I * K)(i, j) = \sum_m \sum_n I(i-m, j-n) K(m, n)$$

Lập trình Python

Định nghĩa mạng CNN ngắn gọn bằng PyTorch:

import torch.nn as nn
class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = nn.Conv2d(3, 16, kernel_size=3)

Vector Hóa Ngôn Ngữ (Embeddings) & Mạng Tuần Tự

Làm thế nào để chuyển từ văn bản chữ viết sang số học tính toán? Chúng ta học cách ánh xạ các từ thành các vector đa chiều (Embeddings) thông qua không gian vectơ hình học tuyến tính.

Bản chất toán học

Độ đo khoảng cách Cosine (Cosine Similarity) đo mức độ giống nhau về nghĩa giữa 2 từ:

$$\text{Similarity} = \frac{\vec{u} \cdot \vec{v}}{\|\vec{u}\| \|\vec{v}\|}$$

Lập trình Python

Sử dụng thư viện Hugging Face sinh vector embedding:

from sentence_transformers import SentenceTransformer
model = SentenceTransformer('all-MiniLM-L6-v2')
vectors = model.encode(["Học AI rất vui", "Trí tuệ nhân tạo"])

Cơ Chế Tự Chú Ý (Self-Attention)

Chúng ta liên kết mọi mảnh ghép đã học: Toán ma trận, Hàm Sigmoid/Softmax và Vector Embedding để tạo ra trái tim của ChatGPT - cơ chế Chú ý giúp mô hình hiểu ngữ cảnh dài cực tốt.

Bản chất toán học

Tính điểm tương đồng giữa Query (Q), Key (K) và ánh xạ thông tin từ Value (V):

$$\text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

Lập trình Python

Tính Attention tinh gọn bằng PyTorch:

import torch
import torch.nn.functional as F
def attention(Q, K, V):
    scores = torch.matmul(Q, K.transpose(-2, -1)) / np.sqrt(Q.shape[-1])
    return torch.matmul(F.softmax(scores, dim=-1), V)
