1. Từ Tuyến Tính sang Xác Suất (Hàm Sigmoid)

Trong học máy, chúng ta tính toán đầu ra tuyến tính trước: $z = w^T x + b$. Đầu ra $z$ này có thể nằm bất kỳ đâu từ $-\infty$ tới $+\infty$.

Để đưa về dạng xác suất (nằm giữa 0 và 1), chúng ta sử dụng Hàm kích hoạt Sigmoid:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Tính chất vật lý của Sigmoid: Nó biến số dương lớn thành số gần bằng 1, số âm lớn thành gần bằng 0, và giá trị đúng bằng 0 sẽ tương ứng xác suất $0.5$. Đây cũng chính là ngưỡng quyết định (decision threshold) mặc định của phân loại nhị phân.

2. Hàm Mất Mát: Binary Cross-Entropy Loss

Để huấn luyện mô hình, ta cần đo lường độ sai lệch. Hàm mất mát Binary Cross-Entropy (BCE) hay còn gọi là Log Loss đo lường xác suất sai lệch:

$$J(w, b) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log(\hat{y}^{(i)}) + (1 - y^{(i)}) \log(1 - \hat{y}^{(i)}) \right]$$

Hãy phân tích sâu sắc công thức này:

  • Khi nhãn thật $y = 1$: Loss sẽ là $-\log(\hat{y})$. Nếu dự đoán $\hat{y} \to 1$, Loss sẽ $\to 0$. Nếu dự đoán $\hat{y} \to 0$, Loss sẽ tăng lên $+\infty$.
  • Khi nhãn thật $y = 0$: Loss sẽ là $-\log(1 - \hat{y})$. Nếu dự đoán $\hat{y} \to 0$, Loss sẽ $\to 0$. Nếu dự đoán $\hat{y} \to 1$, Loss sẽ tăng lên $+\infty$.

3. Thuật toán Tối ưu hóa: Gradient Descent

Để cực tiểu hóa hàm lỗi $J(w, b)$, chúng ta tính đạo hàm riêng (độ dốc) theo từng tham số để điều chỉnh chúng ngược chiều gradient:

$$\frac{\partial J}{\partial w} = \frac{1}{m} X^T (\hat{y} - y), \quad \frac{\partial J}{\partial b} = \frac{1}{m} \sum_{i=1}^{m} (\hat{y}^{(i)} - y^{(i)})$$

Sau đó cập nhật trọng số với tham số học tập (Learning Rate) $\alpha$:

$$w := w - \alpha \frac{\partial J}{\partial w}, \quad b := b - \alpha \frac{\partial J}{\partial b}$$

4. Lập trình Hướng Đối Tượng Scratch

Sau khi đã nắm vững lý thuyết, hãy viết một class LogisticRegressionScratch hoàn chỉnh dưới dạng hướng đối tượng trong Python.

 logistic_regression.py
Python 3 
import numpy as np

class LogisticRegressionScratch:
    def __init__(self, lr=0.01, epochs=1000):
        self.lr = lr
        self.epochs = epochs
        self.weights = None
        self.bias = None
        self.loss_history = []
        
    def fit(self, X, y):
        m, n = X.shape
        self.weights = np.zeros(n)
        self.bias = 0.0
        
        for epoch in range(self.epochs):
            # 1. Tính toán đầu ra & đưa qua Sigmoid
            z = np.dot(X, self.weights) + self.bias
            y_pred = 1 / (1 + np.exp(-z))
            
            # 2. Tính đạo hàm Gradient
            dw = (1/m) * np.dot(X.T, (y_pred - y))
            db = (1/m) * np.sum(y_pred - y)
            
            # 3. Cập nhật trọng số
            self.weights -= self.lr * dw
            self.bias -= self.lr * db
            
    def predict_proba(self, X):
        z = np.dot(X, self.weights) + self.bias
        return 1 / (1 + np.exp(-z))
        
    def predict(self, X, threshold=0.5):
        proba = self.predict_proba(X)
        return (proba >= threshold).astype(int)
