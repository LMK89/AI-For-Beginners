🧠 PERCEPTRON

Chuyên Gia Phân Loại Đơn Giản

📚 Khái Niệm Cơ Bản

Perceptron là một mô hình máy học đơn giản nhất, được phát minh năm 1957 bởi Frank Rosenblatt. Nó có thể phân loại dữ liệu thành hai lớp (binary classification) - Đúng/Sai, Spam/Không Spam, Mèo/Chó.

Cách hoạt động: Perceptron nhận dữ liệu đầu vào, tính toán một giá trị, rồi quyết định: "Lớp +1 hay -1?"

🔄 4 Trạng Thái Hoạt Động

Trạng Thái Đầu Vào (Input) Xử Lý Đầu Ra (Output) Đánh Giá
1. Khởi Tạo w = [0,0,0] Trọng số ngẫu nhiên Chưa học gì ⚠️ Sai
2. Tính Toán x = [1, 2, 3] y = w·x = 1+4+9 = 14 Kết quả: +1 ⚠️ Có thể
3. So Sánh Kết quả = +1, Đúng = +1 Không cần cập nhật Giữ nguyên w ✅ Đúng
4. Sai Kết quả = +1, Đúng = -1 w = w - η·x Cập nhật trọng số ⚠️ Học

📊 Sơ Đồ Quy Trình

┌─────────────┐
│  Dữ liệu    │
│ x=[x₁,x₂]   │
└──────┬──────┘
       │
       ▼
  ┌─────────────────────┐
  │ Tính tổng trọng số  │
  │  z = w·x + b        │
  │  z = w₁x₁ + w₂x₂    │
  └──────┬──────────────┘
         │
         ▼
    ┌─────────────┐
    │  Hàm Step   │ ← BƯỚC QUYẾT ĐỊNH
    │ if z ≥ 0:  │
    │    → +1     │
    │ else:      │
    │    → -1     │
    └──────┬──────┘
           │
           ▼
       ┌────────┐
       │ Output │  ← KẾT QUẢ
       │ +1/-1  │
       └────────┘

🔄 NẾU SAI: Cập nhật w = w + η·x·y
   (η = learning rate)

💻 Code Ví Dụ

Cách 1: Tính Toán Đơn Giản ✅

import numpy as np

# Dữ liệu
x = np.array([1, 2])    # 2 features
w = np.array([0.5, -0.5])  # Trọng số
b = 0.1                  # Bias

# Tính toán
z = np.dot(x, w) + b    # z = 1*0.5 + 2*(-0.5) + 0.1 = -0.4
output = 1 if z >= 0 else -1  # output = -1

print(f"Tính toán: {z:.2f}")
print(f"Kết quả: {output}")  # -1

Cách 2: Hàm Kích Hoạt Step ✅

def step_activation(z):
    """Hàm bước - quyết định dựa trên ngưỡng 0"""
    return 1 if z >= 0 else -1

# Kiểm tra
z_values = [-2, -0.5, 0, 0.5, 2]
for z in z_values:
    y = step_activation(z)
    print(f"z={z:>4} → y={y}")
# Output:
# z=-2.0 → y=-1
# z=-0.5 → y=-1
# z= 0.0 → y=1
# z= 0.5 → y=1
# z= 2.0 → y=1

Cách 3: Vòng Lặp Huấn Luyện ⚠️

def train_perceptron(X, y, learning_rate=0.1, epochs=10):
    """Huấn luyện Perceptron"""
    w = np.zeros(X.shape[1])  # Khởi tạo w

    for epoch in range(epochs):
        for i, x in enumerate(X):
            z = np.dot(x, w)
            pred = 1 if z >= 0 else -1

            # Nếu sai, cập nhật
            if pred != y[i]:
                w = w + learning_rate * x * y[i]

    return w

# Dữ liệu huấn luyện (2D)
X = np.array([[1, 2], [2, 1], [3, 3]])
y = np.array([1, 1, -1])

w = train_perceptron(X, y, learning_rate=0.1, epochs=5)
print(f"Trọng số cuối: {w}")

🌍 Ứng Dụng Thực Tế

📧 Phân Loại Email (Spam vs Không Spam)

Dữ liệu tốt: ✅

  • Email có từ "khuyến mãi", "giảm giá" nhiều → Spam
  • Email từ công ty có tên rõ → Không Spam
  • Độ dài email đều đặn

Dữ liệu xấu: ❌

  • Email không có từ, chỉ có số
  • Dữ liệu không cân bằng (99% Spam, 1% Không)

🏠 Dự Đoán Giá Nhà (Rẻ vs Đắt)

Features:

  • Diện tích (m²)
  • Số phòng
  • Khoảng cách từ trung tâm (km)

Dữ liệu tốt: ✅ Khoảng giá rõ ràng (< 50 tỷ vs > 100 tỷ)

Dữ liệu xấu: ❌ Giá trị trung gian (70-80 tỷ) → Khó phân loại

🍎 Phân Loại Trái Cây (Táo vs Cam)

Features: Màu sắc RGB, Độ cứng, Kích thước

✅ Tốt: Màu đỏ rõ vs Màu cam rõ

❌ Xấu: Trái cây vàng (vừa táo vàng vừa cam) → Nhầm lẫn

📝 Tóm Tắt

Perceptron là gì:

  • ✅ Mô hình phân loại đơn giản, nhị phân (2 lớp)
  • ✅ Dùng hàm Step để quyết định kết quả
  • ✅ Học bằng cách cập nhật trọng số khi sai
  • ⚠️ Chỉ hoạt động tốt với dữ liệu tuyến tính phân tách
  • ❌ Không thể giải quyết vấn đề XOR

Khi nào dùng Perceptron:

  • ✅ Dữ liệu 2 lớp rõ ràng
  • ✅ Cần mô hình đơn giản, nhanh
  • ❌ Dữ liệu phức tạp, không tuyến tính
  • ❌ Cần xác suất hoặc độ tin cậy

  • η = 0.01 → Học chậm ⚠️
