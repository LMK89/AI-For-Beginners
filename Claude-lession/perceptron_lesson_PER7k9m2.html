🧠 Perceptron

Mô Hình Phân Loại Nhị Phân Đầu Tiên

📚 Khái Niệm Cơ Bản

Perceptron là một thuật toán phân loại nhị phân (binary classification) - chỉ có thể phân chia dữ liệu thành 2 lớp (+1 hoặc -1).

Ý tưởng chính:

  • Có một đường ranh giới (hyperplane) chia dữ liệu thành 2 phần
  • Dùng trọng số (weights) để tìm ra đường ranh giới tối ưu nhất
  • Huấn luyện bằng cách điều chỉnh trọng số theo sai số (error)

Công thức Perceptron:

y = f(w·x + b) Trong đó: - w = vector trọng số (weights) - x = vector đầu vào (features) - b = bias (hệ số dịch) - f = hàm kích hoạt bậc thang (step function)

Bảng So Sánh Chi Tiết:

Trạng Thái Input Xử Lý Output Đánh Giá
① Khởi Tạo Dữ liệu train w = [0,0,0], bias = 0 Trọng số = 0 ⚠️ Ngẫu nhiên
② Dự Đoán Sai x_i tích cực (đúng = +1) Nếu y ≤ 0 → cộng w w = w + η·x ✅ Điều chỉnh
③ Dự Đoán Sai x_i tiêu cực (đúng = -1) Nếu y > 0 → trừ w w = w - η·x ✅ Điều chỉnh
④ Hội Tụ Lặp nhiều vòng Không còn sai số w = [w1, w2, w3, ...] ✅ Hoàn thành

💾 Data Tốt vs Data Xấu

Data Tốt cho Perceptron ✅

Dữ liệu tuyến tính có thể phân tách:

  • Có đường thẳng/mặt phẳng chia hai lớp
  • Ví dụ: Spam detection (email spam vs không spam)
  • Ví dụ: Nhận dạng hình tròn vs hình vuông đơn giản

Data Trung Bình ⚠️

Dữ liệu tuyến tính nhưng có nhiễu:

  • Phần lớn điểm phân tách tốt nhưng có vài ngoại lệ
  • Perceptron sẽ cố gắng nhưng kết quả không hoàn hảo
  • Cần tăng số iteration hoặc điều chỉnh learning rate

Data Xấu cho Perceptron ❌

Dữ liệu không tuyến tính có thể phân tách:

  • Không có đường thẳng nào chia được 2 lớp (XOR problem)
  • Ví dụ: Hai lớp chồng lấp nhau phức tạp
  • Giải pháp: Dùng mạng nơ-ron nhiều lớp (MLP)

💻 Code Python - Triển Khai Perceptron

Code Đơn Giản (Easy):

import numpy as np class SimplePerceptron: def __init__(self, learning_rate=0.1): self.lr = learning_rate self.weights = None def train(self, X, y, epochs=100): n_features = X.shape[1] self.weights = np.zeros(n_features) for epoch in range(epochs): for xi, target in zip(X, y): # Tính dự đoán: z = w·x z = np.dot(self.weights, xi) # Hàm kích hoạt bậc thang prediction = 1 if z >= 0 else -1 # Cập nhật nếu dự đoán sai if prediction != target: self.weights += self.lr * target * xi def predict(self, X): return np.sign(np.dot(X, self.weights)) # Ví dụ sử dụng X = np.array([[0, 0], [1, 1], [1, 0], [0, 1]]) y = np.array([-1, 1, 1, 1]) model = SimplePerceptron() model.train(X, y, epochs=50) print("Trọng số:", model.weights) print("Dự đoán:", model.predict(X))

🎯 Điểm Chính:

  • Perceptron = Mô hình phân loại nhị phân đơn giản nhất
  • Cách hoạt động: Tìm đường ranh giới tuyến tính chia 2 lớp
  • Huấn luyện: Điều chỉnh trọng số khi dự đoán sai
  • Ưu điểm: Đơn giản, nhanh, hiểu được
  • Nhược điểm: Chỉ làm việc với data tuyến tính phân tách
  • Kế Tiếp: Multi-layer Perceptron (MLP) cho dữ liệu phức tạp

📖 Bài Học Tiếp Theo:

  • Multi-layer Perceptron (MLP) - Mạng nơ-ron nhiều lớp
  • Hàm Kích Hoạt (Activation Functions) - ReLU, Sigmoid, Tanh
  • Backpropagation - Lan truyền ngược để tính gradient
  • Convolutional Neural Networks (CNN) - Cho xử lý ảnh
