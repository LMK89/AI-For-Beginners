📖 Perceptron là gì?

Perceptron là một mô hình phân loại nhị phân được Frank Rosenblatt phát minh năm 1957. Nó là tiền thân của các mạng nơ-ron hiện đại và hoạt động như một bộ não nhân tạo cơ bản.

🎯 Công dụng: Nhận dạng hình ảnh, phân loại dữ liệu thành 2 nhóm (Có/Không, Đúng/Sai, Mèo/Chó, v.v.)

🔧 Cách Hoạt Động

┌─────────────────────────────────────┐ │ INPUT (Dữ liệu vào) │ │ x = [x₁, x₂, x₃, ..., xₙ] │ └──────────┬──────────────────────────┘ │ ▼ ┌─────────────────────────────────────┐ │ TÍNH TỔNG CÓ TRỌNG SỐ │ │ z = w₁x₁ + w₂x₂ + w₃x₃ + ... + b │ └──────────┬──────────────────────────┘ │ ▼ ┌─────────────────────────────────────┐ │ ACTIVATION FUNCTION (Hàm kích hoạt)│ │ if z ≥ 0: output = +1 (LỚP 1) │ │ if z < 0: output = -1 (LỚP 2) │ └──────────┬──────────────────────────┘ │ ▼ ┌─────────────────────────────────────┐ │ OUTPUT: Dự đoán +1 hoặc -1 │ └─────────────────────────────────────┘

⚡ 3 Trạng Thái Hoạt Động của Perceptron

Perceptron có thể được nhìn nhận qua 3 trạng thái khác nhau:

✅ Trạng Thái 1: Phân Loại Đúng

INPUT: Ảnh mèo (features: [tai, mắt, mũi, lông]) │ ▼ z = 0.5 × 1 + 0.3 × 1 + 0.2 × 1 + 0.4 × 1 = 1.4 │ ▼ z ≥ 0? ✓ CÓ │ ▼ OUTPUT: +1 (Dự đoán là mèo) ✓ ĐÚNG!

⚠️ Trạng Thái 2: Biên Giới (Lưỡng Lự)

INPUT: Ảnh mờ (khó xác định) │ ▼ z = 0.5 × 0.5 + 0.3 × 0.5 + 0.2 × 0.5 + 0.4 × 0.5 = 0.2 │ ▼ z ≥ 0? ✓ CÓ (nhưng rất sát ngưỡng!) │ ▼ OUTPUT: +1 (Dự đoán là mèo) ⚠️ HƠI NHƯ!

❌ Trạng Thái 3: Phân Loại Sai

INPUT: Ảnh chó (features: [tai, mắt, mũi, lông]) │ ▼ z = 0.5 × 1 + 0.3 × 0 + 0.2 × 1 + 0.4 × 1 = 0.9 │ (cái "tai" của chó khác mèo) ▼ z ≥ 0? ✓ CÓ │ ▼ OUTPUT: +1 (Dự đoán là mèo) ❌ SAI!
Trạng Thái Giá trị Z Quyết Định Kết Quả Đánh Giá
✅ Đúng z = 1.4 z ≥ 0 ➜ +1 Dự đoán = Thực tế ✓ HOÀN HẢO
⚠️ Biên Giới z = 0.2 z ≥ 0 ➜ +1 Sát ngưỡng 0 ⚠ NGUY HIỂM
❌ Sai z = -0.8 z < 0 ➜ -1 Dự đoán ≠ Thực tế ✗ CẦN CẢI THIỆN

🎓 Quá Trình Huấn Luyện Perceptron

Perceptron học từ dữ liệu bằng cách điều chỉnh trọng số (weights) để giảm lỗi.

🔄 Vòng Lặp Huấn Luyện

BƯỚC 1: Bắt đầu │ ▼ w₀ = [0.1, 0.2, 0.3, 0.1] (trọng số ban đầu) │ ├─────────┐ │ │ ▼ ▼ BƯỚC 2 & 3: Lấy 1 ví dụ huấn luyện • Tính z = w·x • So sánh với kết quả thực tế │ ▼ BƯỚC 4: CÓ LỖI? Có ──────► w = w + η·x (cập nhật) │ Không ────► Không làm gì │ ├──────────────────────┘ ▼ BƯỚC 5: Lặp lại 100 lần │ ▼ HOÀN THÀNH: Model huấn luyện xong!

💻 Code Huấn Luyện

def train_perceptron(X_train, y_train, iterations=100, learning_rate=0.1): # Khởi tạo trọng số weights = np.zeros(X_train.shape[1]) bias = 0 for epoch in range(iterations): for i, x in enumerate(X_train): # Dự đoán z = np.dot(x, weights) + bias y_pred = 1 if z >= 0 else -1 # Nếu dự đoán sai, cập nhật if y_pred != y_train[i]: weights += learning_rate * x * y_train[i] bias += learning_rate * y_train[i] return weights, bias
Epoch Dữ Liệu z = w·x Dự Đoán Thực Tế Cập Nhật?
1 [1, 1, 0] 0.3 +1 +1 Không
2 [0, 1, 1] -0.2 -1 +1 CÓ ⚡
3 [1, 0, 1] 0.5 +1 +1 Không

📊 Dữ Liệu Tốt vs Xấu cho Perceptron

✅ DỮ LIỆU TỐT

Lớp A Lớp B ● ● ● ■ ■ ■ ● ● ■ ■ ● ● ● ┼─────────────┼ ■ ■ ■ ↑ Đường phân tách (Linear) ✓ Có thể tách bằng 1 đường thẳng ✓ Dữ liệu rõ ràng, không lộn xộn ✓ Perceptron → HOẠT ĐỘNG TỐT!
Ví dụ thực tế: Email Spam vs Normal
  • Spam thường có: nhiều link, ký tự lạ, từ "Mua ngay"
  • Normal thường có: ít link, từ bình thường, có chữ ký
  • → Dễ tách biệt ✓

❌ DỮ LIỆU XẤU

Lớp A Lớp B ● ■ ● ■ ● ● ■ ● Không thể tách ■ ● ■ ● ■ bằng đường ● ■ ● ■ thẳng! ● ■ ● ❌ Các điểm xen kẽ nhau ❌ Dữ liệu lộn xộn ❌ Perceptron → KHÔNG HOẠT ĐỘNG!
Ví dụ thực tế: Phân loại tuổi (Trẻ vs Già) chỉ bằng 1 feature (ví dụ: chiều cao)
  • Người trẻ và người già đều có thể cao hoặc thấp
  • → Dữ liệu xen kẽ, không tách rời ❌
  • Cần nhiều features (chiều cao, số nếp nhăn, tốc độ v.v.) hoặc model khác
Tiêu Chí ✅ Tốt ❌ Xấu
Tách Biệt 2 lớp tách rời bằng đường thẳng 2 lớp xen kẽ, lộn xộn
Số Features Đủ để phân tách (2-10) Quá ít hoặc quá nhiều
Noise (Lỗi) Ít điểm nhiễu Nhiều điểm ngoại lệ
Kích Thước Đủ lớn (100+ mẫu) Quá nhỏ (< 10 mẫu)
Cân Bằng Hai lớp bằng nhau (~50-50) Một lớp = 90%, lớp khác = 10%

🌍 Các Use Case Thực Tế

1️⃣ Email Spam Detection

Bài toán: Phân loại email là Spam hay Normal
Features: Số link, số từ lạ, từ khóa spam ("Mua ngay", "Chiến thắng")
Output: +1 = Spam, -1 = Normal
Kết quả: Perceptron đạt ~85% độ chính xác ✓ TỐT

2️⃣ Iris Flower Classification

Bài toán: Phân loại 2 loài hoa Iris
Features: Chiều dài, chiều rộng cánh hoa
Output: +1 = Setosa, -1 = Versicolor
Kết quả: Perceptron đạt ~98% độ chính xác ✓ TUYỆT VỜI

3️⃣ Sonar Signal Classification

Bài toán: Phân loại tín hiệu sonar (Đá vs Kim loại)
Features: 60 giá trị tần số khác nhau
Output: +1 = Đá, -1 = Kim loại
Kết quả: Perceptron đạt ~75% độ chính xác ✓ KHÁC, cần model phức tạp hơn

❌ Khi KHÔNG nên dùng Perceptron:

  • XOR Problem: Không thể tách XOR bằng đường thẳng → Cần MLP (Multi-layer Perceptron)
  • Dữ liệu nhiều tầng: Khi 2 lớp lồng vào nhau → Cần Neural Network sâu
  • Dữ liệu lớn (Big Data): Slow, cần SGD hoặc các thuật toán tối ưu khác

💪 Bài Tập Thực Hành

Bài 1: Dự Đoán Không Khí

Yêu cầu: Dự đoán xem không khí hôm nay có tốt hay không, dựa trên:

  • Độ ẩm: 1-10 (cao → 10, thấp → 1)
  • AQI (chất lượng không khí): 1-10 (tốt → 10, xấu → 1)

Features: [humidity, AQI]

Output: +1 = Tốt, -1 = Xấu

📝 Giải pháp:
w = [0.3, 0.4] bias = -3.5 def predict(humidity, aqi): z = 0.3*humidity + 0.4*aqi - 3.5 return 1 if z >= 0 else -1 # Test: print(predict(8, 9)) # Ẩm cao, không khí tốt → +1 ✓ print(predict(3, 2)) # Ẩm thấp, không khí xấu → -1 ✓

✅ Tóm Tắt Bài Học

🎯 Khái Niệm Chính
  • Perceptron = Binary Classifier
  • Dùng trọng số để phân loại
  • Học bằng Gradient Descent
⚙️ Cách Hoạt Động
  • Tính z = w·x + b
  • Nếu z ≥ 0: output = +1
  • Nếu z < 0: output = -1
✅ Dữ Liệu Tốt
  • 2 lớp tách rời
  • Có thể chia bằng đường thẳng
  • Ít nhiễu, cân bằng
❌ Giới Hạn
  • Chỉ phân loại 2 lớp
  • Không giải XOR
  • Cần dữ liệu Linear

🎓 Bước Tiếp Theo

Sau khi hiểu Perceptron, bạn sẵn sàng học:

  • Multi-layer Perceptron (MLP) - Mạng nơ-ron với nhiều lớp
  • Backpropagation - Cách huấn luyện mạng sâu
  • Convolutional Neural Networks (CNN) - Cho xử lý ảnh
  • Recurrent Neural Networks (RNN) - Cho xử lý chuỗi
