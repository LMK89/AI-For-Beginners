📚 Perceptron là gì?

Định nghĩa: Perceptron là mô hình phân loại nhị phân đơn giản nhất, gồm một neuron có khả năng tách hai lớp dữ liệu bằng một hyperplane (đường/mặt phẳng).

Lịch sử: Được phát minh năm 1957 bởi Frank Rosenblatt từ Phòng Thí Nghiệm Aeronautical Cornel. Đó là nỗ lực đầu tiên để tạo ra máy tính thần kinh tương tự như các mô hình hiện đại.

Công dụng:

  • ✅ Phân loại dữ liệu thành 2 nhóm (0 hoặc 1, Dương hoặc Âm)
  • ✅ Học từ ví dụ (dữ liệu huấn luyện)
  • ✅ Điều chỉnh trọng số để cải thiện dự đoán

⚙️ Công Thức Perceptron

Công thức tính toán:

y(x) = f(wTx + b)

  • w = Vector trọng số (weights)
  • x = Vector đầu vào (features)
  • b = Bias (độ lệch)
  • f() = Hàm kích hoạt (Activation Function)

Hàm Kích Hoạt (Step Function):

f(x) = {
+1 if x ≥ 0
-1 if x < 0
}

Ý nghĩa: Perceptron đơn giản hóa kết quả thành 2 giá trị (+1 hoặc -1), tương tự như một công tắc On/Off.

(Ranh Giới)		 ⚠️ RỦI RO

🎯 Diagram: Quy Trình Hoạt Động Của Perceptron

Input (x₁, x₂, ...) ↓ [Weights: w₁, w₂, ...] ↓ Weighted Sum: Σ(wᵢ × xᵢ) + b ↓ f() Activation Function ↓ Output: +1 (Class A) hoặc -1 (Class B)

Visualization: Perceptron Phân Chia Dữ Liệu

Không thẻ (Class -1) | Có thẻ (Class +1) ○ ○ ○ | ● ● ● ○ ○ | ● ● ─────────────────────────────────── (Hyperplane) Boundary

Ý tưởng: Perceptron tìm đường phân chia (hyperplane) tốt nhất để tách hai lớp dữ liệu.

🔄 Quá Trình Học (Training) Của Perceptron

Mục tiêu: Điều chỉnh trọng số (w) sao cho perceptron dự đoán chính xác nhất.

Bước 1: Khởi Tạo Trọng Số

def train_perceptron(data, labels, learning_rate=0.1, epochs=100): w = [0, 0] # Khởi tạo trọng số = 0 b = 0 # Bias = 0 for epoch in range(epochs): for x, y in zip(data, labels): # Tính output z = w[0]*x[0] + w[1]*x[1] + b prediction = 1 if z >= 0 else -1 # Kiểm tra xem dự đoán có sai không if prediction != y: # Cập nhật trọng số w[0] += learning_rate * y * x[0] w[1] += learning_rate * y * x[1] b += learning_rate * y return w, b

Bước 2: Cập Nhật Trọng Số

Công thức cập nhật (Gradient Descent):

w_new = w_old + η × y × x b_new = b_old + η × y

Trong đó:

  • η (eta) = Learning Rate (tốc độ học, thường 0.01 - 0.1)
  • y = Nhãn thực tế (+1 hoặc -1)
  • x = Dữ liệu đầu vào

🔍 Dữ Liệu Tốt vs Dữ Liệu Xấu Cho Perceptron

Loại Dữ Liệu Ví Dụ Kết Quả Lý Do
✅ TỐTCHO PERCEPTRON Dữ liệu tuyến tính có thể phân chia Dự đoán tốt, học nhanh Perceptron là bộ phân loại tuyến tính
❌ KHÔNG TỐT Dữ liệu phi tuyến (XOR problem) Không thể học, luôn sai Perceptron không thể vẽ đường cong
⚠️ RỦI RO Dữ liệu mất cân bằng (99% lớp A, 1% lớp B) Thiên vị về lớp lớn hơn Cần cân bằng dữ liệu trước huấn luyện

Ví Dụ Cụ Thể:

Dữ Liệu TỐTCHO Perceptron:

x = [[1, 1], [2, 2], [-1, -1], [-2, -2]] y = [+1, +1, -1, -1] # Dữ liệu tách rõ ràng, 1 đường thẳng là đủ ✓

Dữ Liệu XẤU Cho Perceptron (XOR Problem):

x = [[0, 0], [0, 1], [1, 0], [1, 1]] y = [-1, +1, +1, -1] # Không thể vẽ 1 đường thẳng để phân chia ✗ # Cần 1 đường cong → Cần mạng nơ-ron sâu hơn

Đáp Án: z = 0.6 + 0.7 + 0.2 = 1.5 → f(1.5) = +1 ✓

🎓 Những Điều Bạn Đã Học:

  • ✅ Perceptron là mô hình phân loại nhị phân đơn giản
  • ✅ Công thức: y = f(wTx + b)
  • ✅ Hàm kích hoạt Step: +1 nếu sum ≥ 0, -1 nếu sum < 0
  • ✅ Học bằng Gradient Descent: cập nhật trọng số từng bước
  • ✅ Chỉ phù hợp với dữ liệu TUYẾN TÍNH
  • ✅ Không thể giải XOR problem
  • ✅ Ứng dụng: Email spam, chẩn đoán, kiểm soát chất lượng

⚠️ Lưu Ý Quan Trọng:

  • 🔴 Perceptron chỉ cho 2 lớp, không cho 3+ lớp
  • 🔴 Không giải được bài toán phi tuyến (XOR)
  • ✅ Dùng Multilayer Perceptron (MLP) hoặc Neural Networks cho bài toán phức tạp
