1Object Detection là gì?

Classification chỉ trả lời "trong ảnh có gì?". Object Detection trả lời thêm câu hỏi "nó nằm ở đâu?" — tức là vừa phải đoán lớp (class), vừa phải đoán khung bao (bounding box) toạ độ (x, y, w, h) của từng vật thể.

Input: 1 tấm ảnh có nhiều vật thể Output: [ { class: "chó", box: (x=40, y=40, w=140,h=120), conf: 0.95 }, { class: "mèo", box: (x=220,y=150,w=120,h=100), conf: 0.89 } ] Classification only : "Ảnh này có chó" → 1 nhãn cho cả ảnh Object Detection : "Có 1 con chó ở góc trái-trên" → nhiều nhãn + toạ độ

23 cách tiếp cận — từ ngây thơ đến hiện đại

Cùng một bài toán "tìm chó trong ảnh", có 3 trường phái xử lý hoàn toàn khác nhau.

❌ Ngây thơ / chậm

Cách 1: Sliding Window

Cắt ảnh thành nhiều ô nhỏ (tile), chạy classifier trên từng ô, ô nào activation cao thì coi như có vật thể.

for tile in slide_windows(image, sizes):
    score = classifier(tile)
    if score > 0.9:
        boxes.append(tile.coords)

Box rất thô, tốn hàng nghìn lần forward-pass ⇒ cực chậm, không dùng trong thực tế.

⚠️ Chính xác nhưng chậm

Cách 2: R-CNN family

Dùng thuật toán (Selective Search) đề xuất trước vài nghìn "vùng nghi ngờ" (Region of Interest), rồi mới chạy CNN + hồi quy toạ độ trên từng vùng.

rois = selective_search(image)   # ~2000 vùng
for roi in rois:
    feat = cnn(roi)
    cls  = svm(feat)
    box  = regressor(feat)

Faster R-CNN cải tiến bằng cách để mạng tự đề xuất ROI (Region Proposal Network) — nhanh hơn nhưng vẫn 2 giai đoạn (2-stage).

✅ Nhanh + Real-time

Cách 3: YOLO / SSD (One-pass)

Chia ảnh thành lưới S×S, mỗi ô lưới 1 lần duy nhất dự đoán luôn cả class + box + confidence. Không cần bước đề xuất vùng riêng.

grid = split(image, S=13)
for cell in grid:
    cls, box, conf = model(cell)  # 1 pass duy nhất

"You Only Look Once" — đây là lý do YOLO chạy được real-time trên video, dùng nhiều trong xe tự lái, camera an ninh.

3Khái niệm lõi: IoU (Intersection over Union)

Để biết 1 box dự đoán "đúng" hay "sai" so với box thật (ground-truth), ta không so bằng mắt mà đo bằng công thức:

Diện tích phần GIAO NHAU (Intersection) IoU = ─────────────────────────────────────── Diện tích phần HỢP NHAU (Union) IoU = 1.0 → 2 box trùng khít hoàn toàn IoU = 0.0 → 2 box không chạm nhau chút nào IoU > 0.5 → thường được coi là "phát hiện đúng" (PASCAL VOC chuẩn)

4Non-Max Suppression — trace từng bước (✓ giữ / ✗ loại)

Model thường bắn ra rất nhiều box chồng lấn cho cùng 1 vật thể. NMS là thuật toán "dọn dẹp": duyệt các box theo confidence giảm dần, giữ box tốt nhất, loại các box overlap quá nhiều (IoU cao) với nó.

Bước 1: Lọc theo ngưỡng confidence (loại box quá yếu, có thể là nhiễu) Bước 2: Sắp xếp box còn lại theo confidence GIẢM DẦN Bước 3: Con trỏ i chạy từ box confidence cao nhất: [ giữ box i ✓ ] → tính IoU(box i, mọi box còn lại) → IoU > ngưỡng ⇒ loại (✗, cùng 1 vật, box thừa) → IoU ≤ ngưỡng ⇒ giữ lại xét tiếp (vật thể khác) lặp lại với box i tiếp theo chưa bị loại

6Use case thực tế

🚗
Xe tự lái — phát hiện người đi bộ, biển báo, xe khác trong thời gian thực (bắt buộc dùng one-pass như YOLO vì cần tốc độ >30 khung hình/giây).
🎥
Camera an ninh — đếm người ra vào, phát hiện vật thể bị bỏ quên, cảnh báo xâm nhập vùng cấm.
🏭
Kiểm tra chất lượng sản phẩm — phát hiện vết nứt, lỗi trên dây chuyền sản xuất, định vị chính xác vị trí lỗi để robot xử lý.
🩺
Y tế — khoanh vùng khối u trong ảnh X-quang/MRI, hỗ trợ bác sĩ định vị vùng bất thường.
🛒
Bán lẻ — đếm/định vị sản phẩm trên kệ hàng (shelf monitoring), tự động thanh toán kiểu "Amazon Go".

✍️ Bài tập nhỏ

Cho 2 box: A = (x=10, y=10, w=100, h=100) và B = (x=60, y=60, w=100, h=100).

1. Tự tính diện tích phần giao nhau (Intersection) và phần hợp nhau (Union) trên giấy.
2. Tính IoU = Intersection / Union.
3. Dùng demo IoU ở mục 3 (kéo x=50, y=50) để đối chiếu kết quả.

💡 Gợi ý: phần giao nhau là hình chữ nhật từ (60,60) đến (110,110) ⇒ diện tích 50×50 = 2500. Diện tích mỗi box = 100×100 = 10000. Union = 10000+10000-2500 = 17500. IoU = 2500/17500 ≈ 0.143.

Hãy tự viết (trên giấy hoặc trong đầu) pseudo-code cho vòng lặp NMS, sau đó bấm nút để đối chiếu với bản mẫu chuẩn.

Ý bạn cần có (checklist)
1. Lọc box theo ngưỡng confidence
2. Sắp xếp box còn lại theo confidence GIẢM DẦN
3. Lặp: lấy box đầu (confidence cao nhất) → giữ ✓
4. Tính IoU giữa box vừa giữ với các box còn lại
5. IoU > ngưỡng → loại ✗ (cùng vật thể)
6. Lặp lại bước 3 với box tiếp theo chưa bị loại
7. Dừng khi không còn box nào để xét
Bản mẫu chuẩn (NMS pseudo-code)
def nms(boxes, conf_th, iou_th):
    boxes = [b for b in boxes
             if b.conf > conf_th]
    boxes.sort(key=lambda b: -b.conf)
    keep = []
    while boxes:
        best = boxes.pop(0)
        keep.append(best)
        boxes = [b for b in boxes
                 if iou(best, b) <= iou_th]
    return keep
