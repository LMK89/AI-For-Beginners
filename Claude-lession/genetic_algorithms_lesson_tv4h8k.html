Genetic Algorithms — dạy máy tính "tiến hóa" lời giải bằng chọn lọc, lai ghép và đột biến, giống hệt cách tự nhiên tạo ra loài thích nghi nhất.

Nếu ý bạn gần giống vậy — bạn đã nắm được 80% tinh thần của bài học rồi đó!
01 — Định nghĩa

GA là gì, nói ngắn gọn?

Thuật toán Di truyền (Genetic Algorithm – GA) là một kỹ thuật tối ưu hóa lấy cảm hứng từ tiến hóa sinh học: duy trì một quần thể (population) các lời giải ứng viên (gọi là gene/cá thể), rồi qua nhiều thế hệ (generation) lặp đi lặp lại 3 phép biến đổi — Chọn lọc, Lai ghép, Đột biến — để dần dần "tiến hóa" ra lời giải tốt hơn, mà không cần tính đạo hàm hay biết cấu trúc toán học của bài toán.

Đề xuất bởi John Holland năm 1975. Không đảm bảo tìm ra lời giải tối ưu tuyệt đối, nhưng cực kỳ hữu dụng khi không gian lời giải quá lớn để duyệt hết (brute-force).

03 — Code tối giản cho từng bước

Cài đặt bằng JavaScript (dễ đọc)

① Khởi tạo & tính fitness

const TARGET = "AI FOR ALL";
const CHARS  = "ABCDEFGHIJKLMNOPQRSTUVWXYZ ";

function randomGene(len) {
  return Array.from({length: len},
    () => CHARS[Math.floor(Math.random() * CHARS.length)]).join("");
}

function fitness(gene) {           // càng gần 1.0 càng tốt
  let match = 0;
  for (let i = 0; i < gene.length; i++)
    if (gene[i] === TARGET[i]) match++;
  return match / TARGET.length;
}

② Chọn lọc kiểu Tournament

function selectParent(population) {
  // Bốc 3 cá thể ngẫu nhiên, giữ lại cá thể fitness cao nhất
  const pool = Array.from({length: 3},
    () => population[Math.floor(Math.random() * population.length)]);
  return pool.sort((a, b) => fitness(b) - fitness(a))[0];
}

③ Lai ghép một điểm cắt

function crossover(g1, g2) {
  const cut = Math.floor(Math.random() * g1.length);
  return g1.slice(0, cut) + g2.slice(cut);
}

④ Đột biến

function mutate(gene, rate = 0.02) {
  return gene.split("").map(
    ch => Math.random() < rate
      ? CHARS[Math.floor(Math.random() * CHARS.length)]
      : ch
  ).join("");
}

05 — Chất lượng dữ liệu / mã hóa gene

Gene nào giúp GA chạy tốt, gene nào phá vòng lặp?

Với GA, "dữ liệu" chính là cách bạn mã hóa lời giải thành gene và cách bạn định nghĩa hàm fitness. Chọn sai hai thứ này thì thuật toán dù đúng vẫn không hội tụ.

✅Tốt

Gene chiều dài cố định, khớp đúng cấu trúc bài toán. Fitness trả về số thực có "độ dốc" — càng gần đáp án điểm càng nhích lên dần.

gene = [x1..x8] bit, fit = số bit khớp / 8

⚠️Trung bình

Gene dư thừa (nhiều cách mã hóa cho cùng 1 lời giải) hoặc quần thể khởi tạo quá giống nhau → hội tụ chậm, dễ kẹt local optimum, cần tăng mutation rate.

gene = hoán vị có phần tử lặp không cần thiết

❌Xấu

Gene chiều dài thay đổi khiến crossover tạo ra cá thể không hợp lệ; hoặc fitness chỉ trả 0/1 (đúng tuyệt đối / sai tuyệt đối) khiến GA không có "độ dốc" để leo — chọn lọc trở thành ngẫu nhiên thuần túy.

fit(g) = 1 nếu g == đáp án tuyệt đối, còn lại luôn = 0

📌 Kinh nghiệm thực tế: nếu quần thể hội tụ quá nhanh (mọi cá thể giống hệt nhau ở thế hệ 5) → đó thường là dấu hiệu thiếu đa dạng ban đầu hoặc mutation rate quá thấp, chứ không phải "may mắn tìm ra đáp án sớm".
